# 演示脚本（3 分钟演示视频 / 现场答辩用）

> 系统：智能车间设备故障诊断与预测性维护系统
> 路线 A：离线模拟模式（默认，无需 API Key）；路线 B：LLM 模式（.env 配置 DeepSeek Key 后自动切换）
> 前置：`setup.bat` 初始化 → `start.bat` 启动 → 浏览器打开 http://localhost:8000

---

## 分幕流程（总时长约 3 分钟）

| 幕 | 操作 | 预期画面 | 讲解话术要点 | 用时 |
| --- | --- | --- | --- | --- |
| 1 登录看板 | 账号 engineer / 123456 登录 | 健康看板：6 台设备统计卡片、健康分布饼图、24h 预警趋势、设备健康列表 | "系统登录后进入设备健康总览，左侧统计卡片展示设备总数、健康/故障数、活跃预警与待处理工单" | 20s |
| 2 故障注入 | 设备监控页选择 EQ-003 → 点击"注入外圈故障" | RMS 曲线立即抬升、预警通知弹出、右上角 WebSocket 连接状态 | "演示故障注入：流引擎按外圈故障特征频率 BPFO≈104Hz 实时合成冲击信号，3σ 与孤立森林立即报警，温度随热惯性缓慢爬升" | 30s |
| 3 实时数据与预测 | 观察波形/频谱图 → 点击"运行预测" | 频谱在 BPFO 特征频率处出现谱峰；预测结论"外圈故障"概率、健康评分下降 | "波形频谱对照特征频率判断故障类型；机器学习模型给出四类概率与健康评分，也可点击退化场景演示查看 48 小时 RUL 外推" | 30s |
| 4 智能诊断 | 进入智能诊断页，输入"EQ-003 振动异常，帮我诊断一下" | 五个智能体步骤标签依次出现（意图识别→数据读取→知识检索→诊断推理→决策方案），回复打字机流式输出，下方依据溯源卡片 | "多智能体编排依次完成意图识别、数据读取、知识检索、诊断推理与决策方案；结论附知识库依据与数据证据，可溯源防幻觉" | 50s |
| 5 一键派单 | 点击"依据此诊断生成工单" | 跳转工单页，新工单来源"智能诊断"、优先级高 | "诊断结论一键转为维护工单，实现诊断-决策-派单闭环" | 20s |
| 6 工单流转 | 工单"开始处理"→"完成" | 状态流转待处理→进行中→已完成，时间戳记录 | "工单按状态流转管理，全程留痕；支持导出运维周报" | 20s |
| 7 知识库 | 知识库页输入"内圈故障有什么特征" | 检索结果带引用编号、来源文档与相似度分数 | "知识库管理支持语料上传与混合检索测试，检索结果即诊断依据的来源" | 20s |
| 8 报告导出 | 监控页/工单页导出报告 | 下载设备诊断报告 Markdown | "系统可导出单设备诊断报告与运维周报，沉淀运维数据" | 10s |
| 9 模式说明 | 顶部标签示意（离线模拟模式/LLM 在线模式） | 标签显示当前模式 | "无 API Key 时系统以离线模式运行（规则+模板+ML+知识库）；配置 DeepSeek Key 后自动切换 LLM 模式，接口与画面完全一致" | 20s |

## 答辩高频问题预案（对应代码位置）

| 可能提问 | 讲解要点 | 代码位置 |
| --- | --- | --- |
| 信号是怎么生成的？ | 轴承故障物理模型：特征频率公式 + 指数衰减冲击串 + 转频调制 + 噪声，seed 固定可复现 | backend/app/services/signal_gen.py |
| 特征怎么提取的？ | 时域 9 维（RMS/峭度/波峰因子…）+ 频域 5 维（主频、BPFI/BPFO/BSF 频带能量），汉宁窗 FFT | backend/app/services/ml/features.py |
| 没有 embedding 模型怎么做向量检索？ | jieba 分词 + 特征哈希 1024 维 + TF 权重 + L2 归一化，余弦即内积；混合关键词 Jaccard 打分 | backend/app/services/rag/vectorizer.py, retriever.py |
| 多智能体怎么编排的？ | 状态对象 + 节点纯函数 + 意图条件分支；每节点记录 trace；LLM 失败逐节点降级离线模板 | backend/app/services/agents/orchestrator.py, nodes.py |
| RUL 怎么算的？ | 健康指标 HI 归一化 → 近期序列最小二乘拟合退化斜率 → 外推至失效阈值 0.15 | backend/app/services/ml/rul.py |
| LLM 输出不合法怎么办？ | 四级降级链：直接解析 → 正则提取 → 截断修复 → 离线兜底（有单元测试覆盖） | backend/app/services/agents/llm_client.py |

## 视频录制建议

- 按上表 9 幕顺序录制，卡点约 3 分钟；每幕停留 3 秒让画面稳定；
- 若录播有口误，按幕重录后剪辑拼接即可；
- 路线 B（LLM 模式）在对话页重复第 4 幕即可体现差异（回复措辞由大模型生成）。
